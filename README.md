# 天堂 3D：地監冒險

向經典《天堂》致敬的第一人稱 3D 格子地監 RPG。從奇岩村出發，深入程序生成的古魯丁地監七層迷宮，討伐盤踞最深處的死亡騎士。

- 🗺️ 每次進入都會重新生成的樓層：房間、走廊、寶箱、巡邏並追擊你的怪物
- ⚔️ 回合制戰鬥：騎士技能、蓄力大招與防禦、中毒/麻痺、首領狂暴
- 🧪 經典道具：紅/橙/白水、藍水、綠水加速、勇水、翡翠藥水、回家卷軸
- ✨ 衝裝系統：對武器/盔甲施法的卷軸，超過安定值有機率蒸發
- 🎨 全部 3D 模型、材質、音效皆以程式即時生成，零圖片音檔

## 開始

```bash
npm install
npm run dev
```

開啟 http://localhost:5173 即可遊玩。`npm run build` 會在 `dist/` 產出可部署到任何靜態主機的網站。

## 操作

| 按鍵 | 功能 |
| :--- | :--- |
| W / S（↑ / ↓） | 前進 / 後退 |
| A / D（← / →） | 左轉 / 右轉 |
| Q / E | 左右平移 |
| Enter | 確認樓梯 |
| Space | 攻擊 |
| Z X C V B | 技能 |
| F / R | 防禦 / 逃跑 |
| 1–8 | 快捷道具 |
| I / M / Esc | 背包 / 地圖 / 選單 |

手機上會顯示虛擬方向鍵，所有行動也都能直接點按鈕。

## 開發
